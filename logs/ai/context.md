## CURRENT STATE
The project is a completed four-page, semantic HTML5 website for the UMSI Engaged Learning Office (ELO). The site is for UMSI undergraduate and graduate students and organizes practical resources around the engaged-learning lifecycle. Deliverable 1 is intentionally unstyled HTML and includes accessible structure, shared navigation, a skip link, images, links, lists, and a footer on every page. The local Git repository is connected to the public GitHub repository `https://github.com/mmiyaji26/client_project_f26`.
